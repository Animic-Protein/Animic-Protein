# PONS·AP·I · Pont constitucional Site ↔ GitHub

Data de constitució: 27 d’agost de 2026  
Estat: `BRIDGE_STATUS: CONSTITUTED-1.0`

## Principi

**La Site viu; GitHub recorda.**

La Site i GitHub són dos òrgans del mateix Còdex, no dues fonts rivals. La Site sosté la superfície interactiva i el metabolisme. GitHub sosté la memòria pública, les actes, els estrats històrics i la possibilitat de reconstrucció.

## Regla de pas

Una Mutatio només pot travessar el pont quan declara:

1. procedència i autoria conegudes;
2. diferència perceptible;
3. estat editorial i epistemològic;
4. drets i consentiment aplicables;
5. relació amb els estrats previs;
6. forma de reversió o retorn al Compost.

Cap sincronització concedeix estat canònic automàticament.

## Contracte tècnic

- La Site exposa `/.well-known/animic-bridge.json`.
- GitHub exposa `/pont-site.json`.
- La comprovació automàtica `Bridge · Site ↔ GitHub` contrasta identitat, URLs i regles de governança.
- Una divergència atura el pas i queda visible com una comprovació fallida; no reescriu cap extrem.

## Recuperació

Si un extrem desapareix o divergeix, l’altre no l’usurpa. Es conserva l’última traça vàlida i la Regidoria decideix si cal restaurar, reconciliar o retornar el canvi al Compost.

> *Relatio non confusio. Memoria non immobilitas. Mutatio non oblivio.*
